Those projects explore supervised learning techniques, model training, hyperparameter tuning, evaluation, and visualization using Python and popular machine learning libraries.

## Projects Overview

### Decision Trees
- Explore decision tree classification and model evaluation.
- Investigate how model configurations affect predictions and performance.

### Support Vector Machines (SVM)
- Implement SVM classifiers using linear, polynomial, RBF, and sigmoid kernels.
- Explore the impact of the regularization parameter `C` on decision boundaries.
- Compare validation accuracies across different kernels.
- Visualize decision boundaries and support vectors.

### Neural Networks
- Build and train a feedforward neural network using TensorFlow/Keras.
- Perform binary classification using the Heart Disease dataset.
- Evaluate training, validation, and test performance.
- Experiment with learning rates and three-fold cross-validation.
- Analyze model accuracy and variability across validation folds.
